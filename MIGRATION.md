# Repository split and migration boundaries

Media Scout was split from the public source repository [dakshagrawa/hermes-workflows](https://github.com/dakshagrawa/hermes-workflows) into the new target `dakshagrawa/media-scout`. The source repository was renamed to [dakshagrawa/production-web-checklist](https://github.com/dakshagrawa/production-web-checklist) and retains its history, issues and protection; it is not replaced by this repository.

The standalone media repository retains its original top-level skill directory names and native plugin path `plugins/media-scout`, so recognizable install paths remain stable apart from the repository owner/name. Its filtered Git commit IDs differ from the source repository because unrelated project history was excluded; original authorship and dates were preserved. Package tags required by upgrade tests are retained with unchanged plugin bytes. Historical references to the source repository describe provenance, not the current install location.

No installation, native profile, live config, channel credential or private data is migrated by this split. Existing installs do not auto-update or auto-enable forwarding/deletion. The plugin does not import the instruction-only `media-library/` into `plugin-data/media-scout/`; migration of live records is deliberately unsupported. Repository package versions and deployed policy versions are separate, and publishing this repository does not deploy or upgrade a live profile.

For a checkout of the Media Scout project, set its remote to `https://github.com/dakshagrawa/media-scout.git` and verify `git remote -v`. The existing checklist repository is now `dakshagrawa/production-web-checklist`; do not replace its history with this filtered Media Scout history. Do not move existing installed skill directories or assume repository changes deploy to them.
